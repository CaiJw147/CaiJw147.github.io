# An Atlas of Seeing

A personal portfolio of photographs, music and writing by Haoran Xu.

This repository contains the public static website. Original import packages,
local writing tools, review records and backups remain outside this repository.

GitHub Pages deploys the `main` branch through the Pages workflow.
Website: https://caijw147.github.io/

To preview locally, run `python -m http.server 8000 --bind 127.0.0.1` in this
directory and open http://127.0.0.1:8000/.

Photographs, recordings and writing remain the property of their respective
creators. Bundled font license notices are retained with the font files.
